# Decisions

> A decision log. Each decision gets its own dated file with the format below.

## Why decision logs matter

Conclusions become wrong over time, but **reasoning is forever**. Three months after a decision, the conclusion may be obsolete, but the reasoning will tell you exactly which assumption broke. That's the only way to learn from your decisions instead of just regretting them.

## File naming

`YYYY-MM-DD-<short-slug>.md`

Example: `2026-04-07-buy-EXAMPLE.md`

## Template

See `_template.md` in this directory for the full template. Key sections:

- **Decision** — one sentence
- **Context** — what you knew, what was uncertain
- **Alternatives Considered** — what you rejected and why
- **Reasoning** — the actual logic
- **Trade-offs Accepted** — what you gave up
- **What Would Change My Mind** — falsification criteria
- **Outcome** — filled in 3-6 months later
- **Lessons → Rules** — extract patterns to `rules.md` or `false-beliefs.md`
