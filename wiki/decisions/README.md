# Decisions

> 这是一个决策日志目录。每个决策都应该独立成一个带日期的文件。

## 为什么决策日志重要

结论会随着时间失效，但**推理过程会长期有价值**。几个月后回头看，结论可能已经过时，但 reasoning 能告诉你当初哪条假设出了问题。

## 文件命名

`YYYY-MM-DD-<short-slug>.md`

示例：`2026-04-07-buy-EXAMPLE.md`

## 模板结构

请使用本目录里的 `_template.md`。关键区块包括：

- **Decision**：一句话说明决定了什么
- **Context**：当时知道什么，不确定什么
- **Alternatives Considered**：其他方案以及为什么没选
- **Reasoning**：真实推理链
- **Trade-offs Accepted**：你接受了哪些代价
- **What Would Change My Mind**：什么证据会让你改判断
- **Outcome**：3-6 个月后补写
- **Lessons -> Rules**：把模式提炼到 `rules.md` 或 `false-beliefs.md`
